## Two-Stage Rocket Simulation

This repository now includes a simple Python program `rocket_sim.py`
that simulates the vertical ascent of a generic two-stage rocket.
The simulation uses approximate, but realistic, values for mass,
thrust, burn times and basic atmospheric drag.

To run the simulation with Python 3:

```bash
python3 rocket_sim.py
```

The program will print a summary of altitude, velocity and remaining
mass at 5 second intervals.
